# Официальный сайт Jomart Jurek

Редактирование текстов и фотографий выполняется через [Pages CMS](https://app.pagescms.org/).

1. Войти через GitHub.
2. Открыть репозиторий `jomart-jurek-site`.
3. Выбрать «Основные тексты сайта» или «Фотогалерея».
4. Внести изменения и сохранить.

После сохранения GitHub автоматически обновляет обычные статические HTML-страницы. Действующий домен подключается отдельно только после окончательной проверки.
